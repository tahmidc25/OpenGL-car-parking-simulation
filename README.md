# 🚗 3D Car Parking (OpenGL)

A 3D car parking simulation built using **OpenGL** as part of a **Computer Graphics course project**. This project demonstrates basic 3D object rendering, camera control, lighting, and user interaction in a simulated parking environment.

## 🎮 Features
- 3D car model with movement and rotation controls  
- Realistic parking area with boundaries and obstacles  
- Camera movement and viewing angles  
- Basic lighting and shading for realistic visuals  
- Collision detection (optional, if implemented)  

## 🧩 Technologies Used
- **OpenGL** (GLUT / FreeGLUT)  
- **C / C++**  
- **GLU** for camera transformations  
- **GLUT** for windowing and keyboard input  

## ⚙️ How to Run
```bash
git clone https://github.com/yourusername/3d-car-parking-opengl.git
cd 3d-car-parking-opengl
g++ main.cpp -lGL -lGLU -lglut -o car_parking
./car_parking
